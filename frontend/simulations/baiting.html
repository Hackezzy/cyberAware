Baiting Simulation

Step through how a single "found" USB drive can compromise a company network. This walkthrough continues the story of Meridian Bookkeeping from the Ransomware simulation.

Step 1 of 6

1. The Drop

An attacker leaves a USB drive in Meridian Bookkeeping's parking lot, with a label designed to be irresistible.

💾

2026_Salary_Review_CONFIDENTIAL

What's happening

  • • The label is chosen specifically to be too interesting to ignore — salary information, layoffs, or bonuses are common bait themes.
  • • A parking lot or lobby, somewhere employees naturally pass through, means the attacker doesn't need to enter the building at all.

2. The Find

An employee walking in spots it and picks it up.

"Huh, someone must have dropped this. 'Confidential Salary Review'? I should probably see whose it is..."

What's happening

Curiosity and a genuine desire to help ("I should find the owner") are both completely normal reactions — the bait is designed around good instincts, not carelessness.

3. The Plug-In

Back at their desk, the employee plugs it into a work computer to check it.

[system] USB device connected: "SanDisk 32GB"

[system] opening drive contents...

What's happening

A work computer, connected to the company network, is exactly where this drive was meant to end up — a home computer with no network access would be far less valuable to the attacker.

4. The Payload

The drive shows one file — opening it runs a hidden program instead of a spreadsheet.

📊 Salary_Review_2026.xlsx.scr

What's happening

.scr is a Windows screensaver file type that can run just like a program — disguised behind a spreadsheet icon and a name that ends in ".xlsx" before the real, hidden extension.

5. The Foothold

Nothing visible opens. In the background, the attacker gains quiet remote access.

[background] installing persistence...

[background] remote access established for attacker

What's happening

This is the same "quiet foothold" moment as the Ransomware simulation — baiting is often just the delivery method, not a different end goal. From here, the attacker could deploy ransomware, steal data, or simply watch.

6. The Aftermath

A single curious click, and the network is compromised — here's how to actually avoid this one.

Security researchers have repeatedly demonstrated this exact scenario in real workplace tests — a meaningful share of planted drives get plugged into a work computer within minutes of being found.

Prevention checklist

  • • Never plug an unknown USB drive into any device, work or personal — hand it to IT or security instead.
  • • A tempting label is itself a warning sign, not a reason to look — genuine confidential files aren't distributed by leaving them on the ground.
  • • Businesses can disable AutoRun and restrict USB ports by policy, so even a plugged-in drive can't silently execute anything.
