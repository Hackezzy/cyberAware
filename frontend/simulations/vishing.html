Vishing Simulation

Step through a voice-phishing call — the phone-call version of the scam, and one of the fastest-growing tactics as attackers start using AI to clone voices. Nothing here is real; "First Meridian Bank" is a made-up bank built just for this walkthrough.

Step 1 of 6

1. The Call

A phone rings. The screen shows a name that looks trustworthy.

Incoming call

First Meridian Bank

(800) 555-0134

What's happening

  • • Caller ID can be spoofed — a phone showing a bank's real name and number proves nothing about who is actually calling.
  • • A call feels more urgent and personal than an email, which is exactly why attackers use it.

2. The Voice

A calm, professional-sounding voice opens with the same greeting a real bank call center would use.

"Thank you for banking with First Meridian. This is fraud prevention calling about unusual activity on your account. Am I speaking with the account holder?"

What's happening

Attackers increasingly use AI-generated or cloned voices to sound calm, professional, and even to imitate someone the victim already knows — a real bank script isn't hard to copy, and neither is a real person's voice anymore.

3. The Pretext

The caller explains a scary-sounding problem they're supposedly already helping to fix.

"We've flagged a $2,340 transfer attempt from your account. We've already blocked it, but I need to verify your identity to secure your account before the attacker tries again."

What's happening

Framing themselves as already protecting you builds trust fast — it's much harder to be suspicious of someone who appears to already be on your side.

4. The Ask

A text message arrives mid-call, and the caller asks for the code in it.

"You should just receive a 6-digit verification code by text — that confirms you're the real account holder. Can you read that back to me?"

SMS: Your First Meridian verification code is 738214. Do not share this code with anyone.

What's happening

That code is a real one-time password, sent because the attacker is simultaneously trying to log in or reset the password on the real account — the text even says not to share it, which the caller is asking to override.

5. The Catch

The code is read aloud. The attacker uses it immediately.

[attacker, real time] entering code 738214 at real login page...

[status] identity verified — password reset granted

What's happening

The code only works for a minute or two, so the attacker uses it the instant it's read out — by the time the call ends, the real account may already be locked out from the other side.

6. The Aftermath

Voice cloning is making this attack harder to spot by ear alone — here's how to actually stay safe on a call.

AI-generated voices and caller ID spoofing are cited as some of the fastest-growing threats to individuals and small businesses, precisely because they defeat "I'd recognize that voice" as a safety check.

Prevention checklist

  • • A real bank will never ask you to read back a one-time code — that code exists specifically to prove a request came from you, not from them.
  • • Hang up and call back using the number on your card or statement, never a number the caller gives you.
  • • Caller ID showing a familiar name or number is not verification — it can be spoofed just as easily as an email display name.
  • • If a call creates pressure to act immediately, that pressure is itself a red flag, regardless of how calm the caller sounds.
