      What makes a URL suspicious?

      The only part of a URL that matters for "where does this actually go" is the domain right before the first single slash — not anything after it, and not brand names that appear earlier as a subdomain. A link like paypal.com.secure-verify.ru contains the word "paypal" but the real domain is secure-verify.ru.

      About the real check above: unlike every other tool on this site, checking a URL against Google Safe Browsing requires sending that URL to a small backend server, which forwards it to Google. Only the URL text is sent — never anything else you type on this site. This is a deliberate, narrow exception to the rest of the site's "nothing ever leaves your browser" design, made because real threat-database checks need a server-side API key that can't safely exist in browser-visible code.
